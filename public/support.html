Frequently asked questions

How do I add the bot to my server?
Click Add to Discord above, pick your server, and authorize it. The bot registers all slash commands automatically — they may take up to an hour to appear, so restart Discord if you don't see them right away.
How do I set up the server rules?
Squared One ships with six default rules. Run /rules to view them, /addrule to add your own, and /postrules to post the full list into any channel. New members are automatically DMed the rules when they join.
How do I post announcements?
Use /announce for formatted messages (supports **bold**, *italic*, `code`, links, and blockquotes).
What moderation commands are available?
/ban, /kick, /timeout (30s to 28 days), and /purge (1–100 messages). Every action checks permissions and role hierarchy, and you can run all of them from the dashboard's Moderation panel too.
How does the dashboard work?
Sign in with Discord at /dashboard. Your access is scoped to the servers you actually belong to, so you can only manage and post to your own communities.
How do I verify members?
If verification is enabled, users can run /verify or click a panel posted with /verification-panel, then complete a CAPTCHA to receive the "Verified" role. The bot also flags suspicious joins (brand-new accounts, default avatars, join bursts) and can kick or ban them automatically.
The bot isn't responding — what now?
First check the status widget above. Then make sure the bot has the permissions it needs (Kick/Ban/Moderate/Manage Messages for moderation) and that it can read the channel. Re-inviting with the default permission set usually fixes most issues.

Troubleshooting

Slash commands aren't showing up
Commands are registered globally on boot and can take up to an hour to propagate. Restart Discord to force a refresh, and make sure the bot is online. If it still doesn't work, check the server's Integrations settings to confirm Squared One is present.
The bot can't DM new members
The bot needs the Server Members privileged intent (enabled under Bot → Privileged Gateway Intents in the developer portal). If the member has DMs disabled, the bot skips them silently.
Moderation commands return a permission error
You need the matching permission (Ban/Kick/Moderate/Manage Messages), and the bot does too. Give the bot those permissions in the role hierarchy — its role must be above the members it manages.
The dashboard redirects me to a login page
That's expected when OAuth login is enabled — sign in with Discord to continue. If you don't want login, the operator can disable it by removing CLIENT_SECRET from the environment.
